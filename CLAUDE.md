# VPS Setup Project

Ты помогаешь настроить VPS сервер с нуля.

## Skill

Используй skill из файла `skills/ubuntu-server-admin/SKILL.md` — там полные инструкции
по каждому компоненту. Перед любым шагом сверяйся с соответствующей секцией skill'а.

## Порядок работы

1. Перед любыми действиями прочитай `SETUP_INFO.md` — там все параметры сервера
2. Начинай с секции 0 skill'а (диагностика текущего состояния), затем по порядку
3. Перед изменением конфигов — делай бекап
4. sudo с паролем агент ввести не может (у Bash и у `!` в Claude Code нет TTY). Как только
   появился sudo-пользователь с паролем — предложи пользователю режим A (он сам запускает
   подготовленный скрипт в отдельном окне терминала) или B (временный NOPASSWD с таймером,
   снять в конце) — см. «Подключение к серверу» в skill'е. Без ответа — режим A
5. Не закрывай SSH до проверки что UFW не заблокировал SSH порт

## Важные правила

- Спрашивай только когда есть реальная развилка (например: сменить SSH порт или оставить 22)
- Если информация уже есть в `SETUP_INFO.md` — не переспрашивай
- После каждого крупного шага проверяй результат и подтверждай успех перед следующим шагом
- При первом подключении к серверу по паролю — попроси пользователя выполнить команду
  в отдельном окне терминала и ввести пароль там

## Модульность

Устанавливай только то, что указано в `SETUP_INFO.md`:
- `INSTALL_AWG=yes` → устанавливай wg-easy + AmneziaWG
- `INSTALL_XRAY=yes` → устанавливай 3x-ui с выбранными транспортами (XRAY_REALITY, XRAY_XHTTP, XRAY_WS)
- Если компонент `=no` — пропускай без вопросов
